# ระบบบริหารจัดการอาคารจอดรถอัจฉริยะ

## จุดประสงค์

ระบบแสดงสถานะช่องจอดรถของอาคาร 4 ชั้น รวม 704 ช่อง แยกตาม 5 โซนในแต่ละชั้น ใช้สำหรับดูภาพรวมสถานะ เปลี่ยนสถานะช่องจอดด้วยเจ้าหน้าที่ และแสดงจำนวนช่องว่างบนจอมอนิเตอร์ใกล้ทางขึ้น ปัจจุบันใช้การปรับสถานะแบบ Manual และเตรียมต่อยอดกับ Sensor ในอนาคต

## วิธีใช้งาน

1. ติดตั้งและเปิด Docker Desktop บน Windows
2. ดับเบิลคลิกไฟล์ `start-server.cmd` เพื่อเริ่มระบบ ระบบจะเปิดหน้าเว็บให้อัตโนมัติที่ [http://localhost:8080](http://localhost:8080)
3. ในการเริ่มใช้งานครั้งแรก ระบบจะสร้างรหัสผ่านผู้ดูแลแบบสุ่มและแสดงในหน้าต่าง CMD ให้บันทึกไว้ จากนั้นเข้าสู่ระบบด้วยชื่อผู้ใช้ `admin` และรหัสผ่านที่สร้างให้
4. เลือกเมนู **จอสรุปแต่ละชั้น** เพื่อเลือกชั้นและดูจำนวนช่องว่างของแต่ละ Zone สำหรับจอมอนิเตอร์ หรือเลือก **แผนผังช่องจอด** เพื่อดูและปรับสถานะรายช่อง

## เทคโนโลยีที่ใช้

- React, TypeScript และ Vite สำหรับหน้าเว็บ
- Python และ FastAPI สำหรับบริการระบบ
- PostgreSQL สำหรับฐานข้อมูล และ Alembic สำหรับจัดการโครงสร้างฐานข้อมูล
- Docker Compose สำหรับเริ่มระบบบนเครื่อง
- WebSocket สำหรับอัปเดตสถานะไปยังหน้าจอแบบเรียลไทม์
- SVG สำหรับแสดงแผนผังช่องจอด
